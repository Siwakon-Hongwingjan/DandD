# สารบัญสถานที่และบทบรรยาย {#d-toc}

> คำบรรยาย เหตุการณ์สุ่ม และการ์ดกลุ่มของแต่ละสถานที่ · ตัวละครเด่นอยู่ใน `character/` (มีตัวชี้ →) · เนื้อเรื่องหลักอยู่ใน `dialog/` · เสริมตารางกติกาใน `locations/` ไม่ได้แทนที่ · สเปกและหลักการ: `docs/superpowers/specs/2026-09-21-dialogue-layer-design.md`

## วิธีอ่าน

| สัญลักษณ์ | ความหมาย |
|---|---|
| 🌅 | คำบรรยายเปิดฉาก อ่านออกเสียงให้ผู้เล่นฟังได้เลย |
| 📜 | บทตายตัว อ่านตามได้ทุกคำ (มีท่าทางกำกับในวงเล็บ) |
| 🎲 | แนวทางให้ DM ด้นต่อ หรือคำบรรยายตอนผู้เล่นทอยผ่าน |
| 💬 | กระเป๋าประโยคสั้นๆ หยิบใช้สุ่มได้ |
| 🎭 | การ์ดเสียงของตัวละคร: จังหวะ สรรพนาม นิสัยการพูด ท่าทาง สิ่งที่ไม่มีวันพูด |
| 🧭 | ทางไปต่อ เป็นประโยคพรรณนา ลิงก์ไปสถานที่ถัดไป |
| 🔗 | ตัวละครนี้ชี้ไปหาใคร หรือที่ไหน |

**หลักที่ทุกบทยึด**
- ตัวละครไม่รู้ว่าอยู่ในเกม ไม่พูดเฉลยข้อมูลเป็นชุดๆ ความลับหลุดผ่านท่าทางและสิ่งที่เลี่ยงพูด
- บทตายตัว **ไม่เฉลยเกินตารางกติกาเดิม** (โดยเฉพาะทางกลับบ้าน ผู้กล้ารุ่นก่อน ตราผนึก)
- ตัวละครที่ต้นฉบับให้ "เงียบ นิ่ง" จะได้สคริปต์ความเงียบ ไม่ยัดบทพูดเพิ่ม
- ชื่อและเบื้องหลังเล็กๆ ที่เพิ่มเข้ามาเป็นค่าตั้งต้น เปลี่ยนได้ตามใจ DM
