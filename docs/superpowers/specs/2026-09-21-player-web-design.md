> **เปลี่ยน stack (2026-09-21):** หน้าเว็บย้ายเป็น Next.js + Vercel (ยังใช้ Firebase Firestore+Auth) ตามแผน `plans/2026-09-21-player-web-nextjs.md` ข้อความ "HTML + JS ธรรมดา ไม่มีขั้น build" ในสเปกนี้ถูกแทนที่ ส่วนข้อมูล/กฎ/หน้าจอยังใช้ตามเดิม · พรอมต์ออกแบบ UI: `specs/2026-09-21-stitch-ui-prompt.md`

> สถานะ: ร่างรอตรวจ (2026-09-21) · แผนลงมือทำ: `docs/superpowers/plans/2026-09-21-player-web.md` · ผู้ใช้อนุมัติแนวทาง Firebase และตัด PIN แล้ว ส่วนที่ 2-4 (หน้าจอ ข้อมูลกติกา ทดสอบ) ผมเสนอค่าตั้งต้นเอง ตรวจได้ทั้งฉบับ · โปรเจกต์ไม่ใช่ git repo จึงไม่มี commit

## เป้าหมาย
เว็บให้ผู้เล่น 6 คน (กัน, อันวาส, ป๋องแป๋ง, หง, ดรีม, เพชร) ดูชีทตัวละคร เลือกอาวุธ ดูสกิลทรี และซื้อของ ส่วน DM ดูชีททุกคนและเป็นผู้กดปลดท่าเอง สไตล์เกมออนไลน์แบบ "ผู้กล้าโล่" (หน้าต่างสถานะ ต้นสกิล)

## ตัดสินใจแล้ว
| เรื่อง | ข้อสรุป |
|---|---|
| โฮสต์ | Firebase แพ็กเกจ Spark (ฟรี): Hosting + Firestore + Auth · หน้าเว็บเป็น HTML + JS ธรรมดา ไม่มีขั้น build |
| ล็อกอิน | **ผู้เล่นไม่มี PIN:** เข้าเว็บ (Auth แบบ anonymous) แล้วเลือกชื่อ เก็บชื่อที่เลือกใน `localStorage` มีปุ่มเปลี่ยนคน · **DM ใช้อีเมล+รหัสผ่าน** บัญชีเดียว |
| ชีท | สไตล์ D&D: ชื่อ, เลเวล, HP/HP สูงสุด, AC, ค่าพลัง 6 ตัว (STR DEX CON INT WIS CHA), หมายเหตุ · DM กำหนดค่าทั้งหมดเอง ผู้เล่นแก้ไม่ได้ |
| อาวุธ | 6 ชนิด (ดาบ โล่ ธนู คัมภีร์ กีต้าร์ คฑา) **ห้ามซ้ำ** ใช้ transaction จอง · เลือกแล้วล็อก (ตราติดตลอด) DM รีเซ็ตได้ · เลือก "ไม่ผูกอาวุธ" ได้ จะได้เส้นทางสกิลของ `unbound-path.md` |
| ปลดท่า | **DM เท่านั้นที่กดปลด** ผู้เล่นเห็นสถานะ (ล็อก/ปลดแล้ว) และเงื่อนไขที่ผู้เล่นรู้ได้ |
| เงิน | เก็บเป็นเหรียญทองแดงจำนวนเต็ม (1 ทอง = 10 เงิน = 100 ทองแดง) แสดงเป็น ทอง/เงิน/ทองแดง |
| ร้านค้า | ผู้เล่นซื้อเอง ระบบหักเงินและเพิ่มของอัตโนมัติ · DM เปิด/ปิดร้านทั้งเกมด้วยสวิตช์เดียว · DM เพิ่ม/ลบของและแก้เงินเองได้ทุกเมื่อ · มี log ให้ DM ดูย้อนหลัง |

## โครงข้อมูล (Firestore)
| เอกสาร | ฟิลด์ | ใครเขียนได้ |
|---|---|---|
| `players/{id}` | `name`, `level`, `hp`, `maxHp`, `ac`, `abilities{str,dex,con,int,wis,cha}`, `notes`, `copper`, `inventory[{itemId,qty}]`, `path` (`null`/`weapon`/`unbound`), `weaponId`, `unboundCenter` (DM เลือกท่ากลางให้ผู้ไม่ผูกอาวุธ), `unlocked[moveId]` · `inventory` = `[{itemId|null, name, qty}]` (ชื่อคัดลอกมาตอนเพิ่ม จึงเพิ่มของนอกร้านได้) | DM: ทุกช่อง · ผู้เล่น: เฉพาะ `copper`, `inventory` (ซื้อของ) และ `path`/`weaponId` ครั้งแรกที่ยังเป็น `null` |
| `weapons/{id}` | `claimedBy` (`null` หรือ id ผู้เล่น) | ผู้เล่นตั้งได้เฉพาะจาก `null` เป็น id ตัวเอง · DM รีเซ็ตได้ |
| `config/game` | `shopOpen` | DM |
| `log/{auto}` | `playerId`, `type` (`buy`/`unlock`/`edit`/`claim`), `detail`, `ts` | ทุกคนเพิ่มได้ ลบ/แก้ไม่ได้ · DM อ่านได้ทั้งหมด |

**ข้อจำกัดที่ยอมรับ (เพราะเล่นกับเพื่อน):** ไม่มี PIN จึงมีคนเลือกชื่อคนอื่นแล้วซื้อของหรือเลือกอาวุธแทนได้ · ราคาที่หักตอนซื้อเป็นค่าจากฝั่งผู้เล่น ไม่ตรวจกับแค็ตตาล็อก · `log` ช่วยให้ DM เห็นย้อนหลัง · ถ้าวันหนึ่งไม่ไว้ใจ ค่อยเพิ่ม PIN หรือตรวจราคาในกฎ · **สิ่งที่ผู้เล่นทำไม่ได้แน่นอน:** เปลี่ยนสถานะ ปลดท่าเอง หรือแก้ชีทที่เป็นของ DM

## ข้อมูลกติกา (ไฟล์ JSON ในเว็บ แปลงจากไฟล์ .md ด้วยสคริปต์)
- `data/weapons.json`: อาวุธ 6 ชนิด แต่ละอัน: `id`, `name`, ชื่ออาวุธเต็ม, `role`, `hitDie`, ท่ากลาง (ฟรี), วงที่ 1 (10 ท่า: `slot`, `id`, `name`, `effect`, `unlock` (เงื่อนไขที่ผู้เล่นรู้ได้), `tier` 🟢🟡🟠🔴, `secret`) · วงที่ 2-3 (ภาพจำลอง) **ไม่ใส่**
- `data/unbound.json`: ท่ากลาง (เลือก 1 จาก 12) และวิชา 10 ท่าของผู้ไม่ผูกอาวุธ
- `data/items.json`: สินค้าในร้าน (`id`, `name`, `price` ทองแดง, `desc`, `category`) คัดจากตารางร้านใน `locations/` ผมร่างให้และคุณตรวจ
- **ห้ามมีข้อมูลลับของ DM:** ถ้อยคำเรื่อง "ถูกผนึก" "ตราผนึก" ความจริงเรื่องทางกลับบ้าน ต้องไม่หลุดเข้า JSON · ท่าลับ (`secret`) แสดงเป็น "❓ ท่าลับ" ล็อกไว้ ไม่มีเงื่อนไข · หลัง DM ปลดจะขึ้น "✨ ท่าลับปลดแล้ว — DM จะแจ้งรายละเอียด" (JSON ไม่เก็บรายละเอียดท่าลับ)

## หน้าจอ
**ผู้เล่น** (มือถือใช้ได้): หน้าเลือกชื่อ → แท็บ **สถานะ** (ชีท D&D + เงิน + กระเป๋า) · **อาวุธและสกิล** (ถ้ายังไม่เลือก: การ์ดอาวุธ 6 ใบ ใบที่ถูกจองเทาและมีชื่อเจ้าของ + ปุ่ม "ไม่ผูกอาวุธ" · ถ้าเลือกแล้ว: ต้นสกิล ท่ากลางกับวงที่ 1 ปลดแล้วสว่าง ล็อกมัว) · **ร้านค้า** (ปิดอยู่จะขึ้น "ร้านปิด")
**DM:** รายชื่อ 6 คน → หน้าเดียวต่อคน: แก้สถานะ เงิน กระเป๋า · ติ๊กปลดท่า/ล็อกคืน · รีเซ็ตอาวุธ · สวิตช์ร้านค้า · log ล่าสุด

## ที่ไม่ทำในเวอร์ชันแรก
ทอยลูกเต๋า · แชต · ระบบต่อสู้ · น้ำหนักของ · รูปโปรไฟล์อัปโหลด · ปุ่มผู้เล่น "ขอปลดท่า" · วงที่ 2-3 ของต้นสกิล · การตรวจราคาฝั่งเซิร์ฟเวอร์

## การทดสอบ
- ตัวแปลงข้อมูล: สคริปต์นับจำนวน (6 อาวุธ × ท่ากลาง 1 + วงที่ 1 ครบ 10 · ผู้ไม่ผูกอาวุธ 12 + 10) และค้นคำต้องห้าม ("ผนึก" ฯลฯ) ต้องไม่พบ
- กฎความปลอดภัย: ทดสอบด้วย Firebase Emulator ยืนยันว่าผู้เล่นแก้ `unlocked`/สถานะไม่ได้ จองอาวุธซ้ำไม่ได้ และแก้ `config/game` ไม่ได้
- เช็กลิสต์ทดสอบมือ: เปิดสองเบราว์เซอร์ (DM + ผู้เล่น) ให้ DM กดปลดท่าแล้วต้องขึ้นที่ผู้เล่นทันที
