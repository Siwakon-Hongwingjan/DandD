## 1. ผู้ใช้ตัดสินใจแล้ว
| เรื่อง | ข้อสรุป |
|---|---|
| โครงโฟลเดอร์ | `dialog/` = **เนื้อเรื่องหลักเท่านั้น** · `character/` = แฟ้มตัวละคร (ตัวพิมพ์เล็กตามโปรเจกต์) · `places/` = ส่วนที่เหลือจาก `dialogue/` เดิม · `locations/` = ตารางกติกา **ไม่แตะ** |
| ใครได้แฟ้ม | ตัวเด่น ⭐ และตัวรองที่มีผลต่อเนื้อเรื่อง **~52 แฟ้ม** (รายชื่อข้อ 3) กลุ่ม/ฝูงชนและตัวรองอื่นอยู่ใน `places/` ตามเดิม |
| การจัดการการ์ดเดิม | **ย้ายการ์ดเดิมทั้งชุดด้วยสคริปต์ ไม่ทิ้งบทที่เขียนไว้** แล้วเขียน "หัวแฟ้ม" ใหม่ไว้บน |
| ระดับหัวแฟ้ม | **แนวทางให้ DM เล่นต่อเอง ไม่ต้องละเอียดทุกข้อ** |

## 2. โครงสร้างเป้าหมาย
```
dialog/     00-สารบัญ.md (ฉากเนื้อเรื่อง) · 01-ep1.md (ย้ายจาก dialogue/06-main-quest-ep1.md)
character/  00-สารบัญ.md (ดัชนีตัวละคร) · 01-halden.md … 52-*.md (หนึ่งคนต่อไฟล์ ขึ้นต้นด้วย <!-- group: ชื่อหมวด -->)
places/     = dialogue/ เดิมทั้งโฟลเดอร์ (mv) ลบการ์ดที่ย้ายออก เหลือ 🌅 เหตุการณ์สุ่ม 🧭 การ์ดกลุ่ม + ตาราง "ใครอยู่ที่นี่"
locations/  ไม่แตะ (ยกเว้น build.py)
```
- `places/00-สารบัญ.md`: ลบส่วนที่ 6 (เนื้อเรื่องหลัก) ออก ย้ายไป `dialog/00-สารบัญ.md`
- หลังย้าย `places/` ไม่มี `06-main-quest-ep1.md` อีก

## 4. วิธีย้ายการ์ด (สคริปต์ Python)
1. `mv dialogue places` แล้ว `mkdir dialog character`; ย้าย `places/06-main-quest-ep1.md` → `dialog/01-ep1.md`
2. หน่วยการ์ด = จาก heading ระดับ 3 ที่มี `{#id}` ตามตารางข้อ 3 จนถึงบรรทัดก่อน heading `###` ถัดไป (ตัดเส้น `---` ท้ายบล็อกที่ติดมา)
3. แฟ้ม = หัวแฟ้มใหม่ (ข้อ 5) + การ์ดเดิมทุกใบที่ระบุ โดยคง heading `###` และ `{#id}` **เดิม** ไว้ทุกตัว (เพื่อให้ลิงก์เดิมทั้งหมด เช่น `(#d-throne-halden)` ยังทำงาน `build.py` จะชี้ข้ามหน้าเอง) ถ้ามีหลายการ์ดให้เรียงตามลำดับที่ปรากฏ ใส่บรรทัดบอกว่ามาจากสถานที่ไหน
4. ใน `places/` แทนที่การ์ดที่ย้ายด้วยตัวชี้หนึ่งบรรทัดแบบ `### <icon> ชื่อ — บทบาทสั้น → แฟ้มตัวละคร` **ไม่ใส่ id เดิม** (กัน id ชน) แล้วดูให้ตาราง/บรรทัด "คนที่นี่" ของสถานที่ยังลิงก์ id เดิมอยู่ (ถูกต้อง เพราะ id เดิมตอนนี้อยู่หน้า character)
5. หลังย้าย นับไบต์เทียบก่อน-หลัง (ผลรวม places+character+dialog ต้อง ≥ ก่อนย้าย) ห้ามข้อความหาย

## 5. รูปแบบหัวแฟ้ม (เขียนใหม่ ~10-15 บรรทัดต่อคน ระดับแนวทาง)
```
<!-- group: ชื่อหมวด -->
## ไอคอน ชื่อ {#c-slug}
*บทบาท · อยู่ที่ไหน (ลิงก์ #d-<สถานที่>) · ฝ่าย*
### 🔒 แฟ้ม (DM เท่านั้น — ห้ามอ่านออกเสียง)
- **อยากได้ / กลัว:** …
- **รู้อะไร:** พูดได้ทันที: … · ต้องทอยถึงจะได้: … · ไม่มีวันบอก: …
- **ความลับ / background:** … (ที่ส่งผลต่อเนื้อเรื่อง)
- **ผลต่อเรื่อง:** ตอนที่ 1: … · ตอนที่ 2-5 (ร่างจาก outline): …
- **🎲 ทอยกับเขา:** ตารางย่อ | ทอยอะไร | ค่าความยาก | ได้อะไร |
- **เล่นยังไง:** 2-3 ประโยค แนวทางด้นต่อ
### 🎭 การ์ดเสียงและบทตายตัว …  (การ์ดเดิมย้ายมาต่อท้าย)
```
- แหล่งข้อมูลหัวแฟ้ม: (ก) ตาราง "ข้อมูลที่รู้ได้" และบริการในไฟล์ `locations/0N-*.md` ของสถานที่นั้น (grep ชื่อตัวละคร) (ข) การ์ดเดิม (ค) `outline.md` หัวข้อ 1, 4, 5 (ง) `section-1-flow.md` ตาราง "เบาะแสรวม" (หัวข้อ 11: S1-S4 ในเมือง, Z1-Z2 ซาก, V1-V5 หมู่บ้าน)
- **ห้ามเฉลยเกินตารางเดิมในบทที่อ่านออกเสียง** ความลับจริงอยู่ในหัวแฟ้มเท่านั้น

## 6. ความจริงเฉพาะ DM (จาก outline.md ใช้ตอนเขียนหัวแฟ้ม)
- **จอมมารวอร์ราธตายไปเมื่อ 30 ปีก่อน** หลังสงครามจบ · ราชสำนักกับศาสนจักร (สภาแห่งรุ่งอรุณ) เสียประโยชน์จากสันติภาพ จึง **สร้างจอมมารปลอม** จ้างนักแสดงเป็นแม่ทัพ จัดฉากบุก ใส่ร้ายชนเผ่าเถ้าถ่าน
- **ชนเผ่าเถ้าถ่านมีเลือดปีศาจจริงแต่เป็นชาวบ้านธรรมดา** ผู้นำคือ **แม่วีซา** หญิงชราที่ถูกป้ายสีเป็น "จอมมาร" (**ไม่ใช่ป้าแวนด้า** ที่เป็นหัวหน้ากลุ่มตะเกียงลับ ชื่อคล้ายกันระวังสับสน)
- **ทางกลับบ้านไม่มีจริง** · **ผู้กล้ารุ่นก่อนมีจริง** ถูกใช้เป็นโฆษณาชวนเชื่อและเครื่องมือกวาดล้าง · **ผู้กล้าหมายเลขสาม** ถืออาวุธที่ไม่มีใครเลือก เป็นหัวหน้าหน่วยนักฆ่า "หน่วยมือเงียบ" (ตอนที่ 4) เขาถูกหลอกเหมือนกัน พูดว่า "ฉันทำทุกอย่างเพื่อกลับบ้าน"
- **อาวุธมี "ตราผนึก"** (หน้าตาเหมือนกุญแจล็อก ที่มุมท่า) มาเรนระงับโหนดที่ผนึกได้ · ตื่นพลังจากการเลือกฝั่งความจริงระงับไม่ได้ · ทิ้งอาวุธได้ตอนที่ 4-5
- **ราชาฮัลเดน** อยู่เบื้องหลังโครงการ ยิ้มอบอุ่น · **ออสริก** ผู้กำกับตัวจริง บอสสุดท้าย (ตอนที่ 5) · **มาเรน** รู้ว่าทางกลับบ้านไม่มี · **รีลลา** เชื่อว่าจอมมารมีจริง (ยืนข้างผู้เล่นได้ภายหลังตามความไว้ใจ) · **แม่ทัพคร็อธ = เซอร์อัลดัส** อดีตอัศวิน ถูกยิงปิดปากด้วยธนูหลวงท้ายตอนที่ 1
- ตัวติดตามเรื่อง: **ความสงสัย** 0-10 (7 ขึ้นไป = ราชาเริ่มรู้ตัว) · ชื่อเสียงผู้กล้า/คนเมือง · ความไว้ใจของผู้สังเกตการณ์
- ตอนที่ 2 ถนนสู่เหนือ (กลุ่มตะเกียงลับ ผู้ลี้ภัยเถ้าถ่าน เมืองกักกันจัดฉาก) · 3 โรงละครชายแดน (แม่ทัพคนที่สอง) · 4 คำสั่งของราชา (กวาดล้างหมู่บ้านมาร นักฆ่า) · 5 ม่านสุดท้าย (พิธีปราบวอร์ราธบนเวที บอสออสริก จบ 4 ทาง) — **ตอนที่ 2-5 เป็นแค่โครงร่าง** ให้ทำเครื่องหมาย "ร่าง" ในหัวแฟ้ม

## 7. งานใน `locations/build.py` (ปัจจุบันสร้าง 2 หน้า: สถานที่ + บทพูด)
1. ปรับเป็น **4 หน้า:** `locations/สถานที่ทั้งหมด.html` (เดิม) · `places/สถานที่และบทบรรยาย.html` · `character/แฟ้มตัวละคร.html` · `dialog/เนื้อเรื่องหลัก.html`
2. `make(src, dlg)` ใช้ซ้ำได้ (dlg=True เดิมคือโหมดบทพูด: ขึ้นบรรทัดใหม่ในย่อหน้า + `00-*.md` เป็นสารบัญแบบ flat) ใช้กับ places/character/dialog ทั้งสาม
3. **character:** ไฟล์ขึ้นต้นด้วย `<!-- group: … -->` ให้ `make()` แทรก h1 หมวดเมื่อหมวดเปลี่ยน (ไฟล์เดียวมี `## ` เดียว = แฟ้มคนหนึ่งคน ห่อเป็นส่วนที่พับ/กางได้)
4. `relink()` เดิมรองรับแค่ 2 หน้า ให้ขยายเป็น N หน้า (หา id ใน `used` ของหน้าอื่นตามลำดับ แล้วชี้ `../โฟลเดอร์/ไฟล์.html#id` ที่ percent-encode) · ปุ่ม "↔" ที่แถบข้างเป็นเมนูสลับ 4 หน้า
5. ข้อจำกัดของตัวแปลง: หัวข้อสูงสุด 4 ขีด (`####`) · id ต้องเป็น `[\w-]` · ลิงก์ในเนื้อหาเป็นแบบ `[ข้อความ](#id)` อย่างเดียว · อย่าใส่ `|` ในเซลล์ตาราง · `*ตัวเอียง*` ต้องมีช่องว่าง/เครื่องหมายก่อน-หลัง · หลังแก้ต้องรันจากโฟลเดอร์ที่ถูกต้อง (`cd locations && python3 build.py`)

## 8. เช็กลิสต์ตรวจก่อนจบ
- รัน build ไม่มี error และไม่มีเตือน "ลิงก์ที่ไม่พบปลายทาง"
- แต่ละหน้า: ไม่มี id ซ้ำ · ไม่มีตัว `*` หลง · ตารางคอลัมน์เท่ากัน (สคริปต์ตรวจแบบเดิม: นับ `<th>/<td>` ต่อแถวใน `<table>`)
- จำนวนแฟ้ม `character/` = 52 · จำนวนการ์ดที่ย้าย = ผลรวม id ในข้อ 3 (นับด้วย grep `{#d-...}` ก่อน-หลัง)
- ฉากเนื้อเรื่องหลัก id `d-mq-1`…`d-mq-6` ยังอยู่ครบใน `dialog/`
- ปรับ `2026-09-21-dialogue-layer-design.md` ให้ตรงโครงใหม่ (ชื่อโฟลเดอร์ ระดับความลึก ที่อยู่ของการ์ด)
- สคริปต์ helper เดิมใน scratchpad ของเซสชันเก่า (`mark.py`) **ไม่ต้องใช้ต่อ** (มันเติมลิงก์ 📖 กับพลิก ✅ ในสารบัญ ทำเสร็จแล้ว)

## 9. เกร็ดการทำงาน (สำหรับเซสชันใหม่)
- ระบบมี hook "Fact-Forcing Gate": **การเขียนไฟล์ใหม่หรือแก้ไฟล์ครั้งแรกอาจถูกบล็อก** ต้องบอกข้อเท็จจริง 4 ข้อ (ไฟล์ที่เรียก · ไม่มีไฟล์ซ้ำ · โครงข้อมูล · คำสั่งผู้ใช้ตามตัวอักษร) แล้วส่งซ้ำ ตอนเขียนไฟล์ใหญ่ให้สร้างไฟล์ด้วยหัวสั้นๆ ก่อน แล้วต่อเนื้อหาด้วย Edit จะได้ไม่ต้องส่งเนื้อหายาวซ้ำ
- การแก้จำนวนมากใช้สคริปต์ Python ผ่าน Bash (เขียนสคริปต์ใน scratchpad) ประหยัดกว่า Edit ทีละจุด
