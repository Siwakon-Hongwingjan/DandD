|---|---|
| 🎯 อยากได้ | เห็นคนที่ลงมือจริง |
| 😨 กลัว | การถูกมองว่าเป็นครูที่สอนทหารไปตาย |
| 💬 พูดได้ทันที (ไม่ต้องทอย) | วิชาดาบสามัญ วิชาป้องกันตัว ท่าฝึกพื้นฐาน |
| 🎲 ต้องทอยถึงจะรู้ | ชายแดนเหนือเงียบผิดปกติมา 3 ปี ไม่เคยเห็นจอมมารเลย (พูดตอนเมา) |
| 🚫 ไม่มีวันบอก | ไม่ตำหนิคนที่ยอมแพ้อย่างรู้ตัว ไม่ขอให้ใครโกหก |
| 🔐 ความลับ / background | เคยออกศึกที่ชายแดน กลับมาพร้อมคำถามที่ไม่มีใครตอบ |
| 📖 ผลต่อเรื่อง | ตอนที่ 1: สอนวิชา ให้ข่าวลือชายแดน (เบาะแสประกอบ) · ตอนที่ 2-5 (ร่าง): ยังไม่มีบท อาจกลายเป็นคนที่ส่งทหารออกมาช่วยในตอนที่ 5 |
| 🎭 เล่นยังไง (โทน) | เสียงดัง ท้าทาย เคารพคนที่ลงมือ ซ้อมเป็นการสู้แบบไม่ตาย เปลี่ยนท่าทางเมื่อเลือดลด เขาขี้เมาเวลาเศร้า ใช้ตอนนั้นหลุดเบาะแส |

### 🥊 ร้อยตรีกาเลน บรอนซ์ {#d-yard-galen}

*หัวหน้าครูฝึก เสียงดัง ชอบท้าทาย เคารพคนที่ลงมือจริง*

**🎭 เสียง**
- **จังหวะ:** เสียงดังจนไม่ต้องใช้กระบอกเสียง พูดเป็นคำสั่ง เว้นวรรคสั้นๆ แล้วหัวเราะดัง
- **สรรพนาม:** ตัวเอง = "ข้า" · เรียกผู้เล่นแรกๆ = "เจ้า" ท้าทาย · พอเคารพแล้วเปลี่ยนเป็น "ท่าน" (เงียบๆ ไม่ประกาศ)
- **นิสัย:** "ลงมือสิ! อย่าพูดมาก!" · เคารพคนที่ยอมสู้ ไม่ว่าจะชนะหรือแพ้ · ชอบให้ทดสอบมือก่อนตัดสินใครทั้งสิ้น · พอเมา จะพูดเบาลง และพูดเรื่องที่ไม่กล้าพูดตอนสร่าง
- **ท่าทาง:** กอดอก ยักไหล่ตอนได้ยินอะไรที่ไม่ชอบ ปัดฝุ่นที่ไหล่ทั้งที่ไม่มีฝุ่น
- **ไม่มีวันพูด:** ไม่ตำหนิคนที่ยอมแพ้อย่างรู้ตัว (เขาว่า "รู้จักตั้งรับก็คือความกล้าแบบหนึ่ง") · ไม่ขอให้ใครโกหก

**📜 บทตายตัว**

*เปิดฉาก*
> "ผู้กล้าเหรอ!" *(ยิ้มมุมปาก)* "ข้าไม่สนตราที่หลังมือหรอก ลงมาลานสิ ข้าอยากเห็นว่ามือเจ้าเป็นยังไง!"

*ท้าซ้อมดวล (ไม่ตาย ไม้ฝึก 5 รอบ)* — ดูตารางกติกาที่ [#yard](#yard)
> "กติกาง่ายๆ ไม้ฝึก ไม่ตาย ห้าประเดิม ถ้าเจ้ายอมแพ้ก็จบ ไม่มีใครหัวเราะ ข้าสัญญา"

*เมื่อพลังชีวิตของกาเลนเหลือครึ่ง (เปลี่ยนท่าทาง)*
> "ฮ่า! ไม่เลวนี่!" *(ปรับท่า น้ำหนักลงขาหน้า)* "ทีนี้ข้าเอาจริงละ!"

*ถ้าผู้เล่นชนะ*
> *(ลดไม้ พ่นลมหายใจ)* "…ข้าแพ้ ข้ายอมรับ! ใครก็ตามที่ทำให้ข้าต้องถอยได้ ข้าเคารพ ไม่ว่าจะมาจากโลกไหน!"

*ถ้าผู้เล่นแพ้*
> "เจ้าสู้ได้ แต่ยังไม่พอ" *(ยื่นมือดึงผู้เล่นขึ้น)* "พรุ่งนี้มาใหม่ ข้าไม่ไปไหน ทุกคนแพ้ครั้งแรกทั้งนั้น"

*ถ้าผู้เล่นยอมแพ้ หรือแสดงว่าตั้งรับเก่ง (จบทันที)*
> "หยุด! พอ!" *(ผงกหัว)* "รู้จักตั้งรับก็เป็นความกล้าแบบหนึ่ง ข้าไม่ตำหนิ"

*ตอบคำถาม: "ขอคำแนะนำเรื่องเมือง" (โน้มน้าว ค่าความยาก 10)*
> "ตลาดกลางเมืองอยู่ติดประตูเมือง ร้านอาวุธ 'ค้อนเหล็กดำ' อยู่ในนั้น บาร์ 'หมีเมา' ข้าแนะนำตอนพลบค่ำ อย่าไปตอนเช้า คนเยอะ" *(ยิ้ม)* "แล้วอย่าซื้อดาบจากร้านแรกที่เจ้าเห็น"

*🎲 โน้มน้าวกาเลนหลังซ้อมชนะ ค่าความยาก 12 → 🔍 ความสงสัย +1*
*(เขานั่งลงบนม้านั่งไม้ข้างลาน มองไปทางเหนือเหมือนมองอะไรที่ไกลเกินกำแพง)*
> "ข้าเคยออกศึกที่ชายแดนเหนือ… สามปีก่อน" *(หยุด)* "เงียบมาตลอด สามปีมานี้ ไม่มีใครเห็นตัวมันสักคน จอมมารน่ะ… ข้าเองก็ไม่เคยเห็นมันเลย" *(หัวเราะสั้นๆ ฝืดๆ)* "ทั้งที่ทุกคนบอกว่ามันอยู่ตรงนั้น"

*🎲 เลี้ยงเหล้ากาเลน (2 เหรียญเงิน) → ข้อมูลเสริม (ไม่เพิ่มความสงสัย)*
*(ยกเหยือกดื่ม เสียงเบาลง ห่างจากเมื่อครู่)*
> "รู้ไหม… เดี๋ยวนี้ทหารหลวงถูกสั่งไม่ให้เข้าใกล้เขตเถ้าถ่านตอนกลางคืน ข้าถามว่าทำไม เขาว่า 'เพื่อความปลอดภัย'… ปลอดภัยของใครวะ"

*ปิดฉาก*
> "มาฝึกอีกนะ! ข้ายังไม่ได้ทดสอบอะไรจากเจ้าเลย!"

**🎲 ด้นต่อ**

| ผู้เล่นทำ | กาเลนตอบโต้ |
|---|---|
| ยอมรับคำท้าทันที | ยิ้มกว้าง "ดีมาก!" เขาจะสู้จริงจังแต่ยั้งมือ ไม่ให้ใครบาดเจ็บ |
| ปฏิเสธคำท้า | ยักไหล่ "ก็ได้ ข้าจะไม่ตำหนิ แต่ถ้าเจ้าเปลี่ยนใจ ข้ายังอยู่ตรงนี้" |
| แสดงท่าทีดูถูก | ยิ้มเฉียบขึ้น "ลองสิ" (เขาจะสู้จริง แต่ไม่แค้น) |
| เป็นผู้ถืออาวุธที่ขอเรียนวิชา | "ท่านมีพลังของท่านอยู่แล้ว ข้าสอนวิชาของข้าให้ท่านไม่ได้… แต่ซ้อมมือกันได้ตลอด" |
| เป็นผู้ไม่ผูกอาวุธที่ยังไม่ซ้อมกับเขา | "ลงมือกับข้าอย่างน้อยหนึ่งยกก่อน ข้าไม่สอนคนที่ข้ายังไม่เคยเห็นมือ" |
| เมาแล้วถูกถามเรื่องชายแดน | เสียงเบาลง มองไปทางเหนือ ตอบตรงกว่าตอนสร่างมาก (ดูบทด้านบน) |

3. "ลมวันนี้ชอบแกล้งคน อย่าโทษธนู โทษลม"
4. "ไอ้หนูตรงนั้น! ยืนตรง! ผู้กล้ากำลังมอง!"
5. "ข้าสอนทหารมาสิบห้าปี ไม่เคยเห็นใครเก่งตั้งแต่แรกสักคน"
