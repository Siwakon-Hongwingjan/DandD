### 🔒 แฟ้ม (DM เท่านั้น — ห้ามอ่านออกเสียง)

| หัวข้อ | รายละเอียด |
|---|---|
| 🎯 อยากได้ | รับใช้ผู้กล้าและศาสนจักรให้ดีที่สุด |
| 😨 กลัว | ความสงสัยในศรัทธาของตัวเอง |
| 💬 พูดได้ทันที (ไม่ต้องทอย) | "ท่านมาเรนบอกว่าอาวุธเลือกหัวใจ" คำสอนของศาสนจักร |
| 🎲 ต้องทอยถึงจะรู้ | ถ้าผู้เล่นทักเรื่องตราหน้าตาเหมือนกุญแจล็อกหลังทอยคัมภีร์ผ่าน เธอไม่เข้าใจแต่จำได้ว่าเห็นบ้าง |
| 🚫 ไม่มีวันบอก | ไม่สงสัยศาสนจักร และไม่รู้ว่ามีผนึกในตรา (ไม่รู้จริงๆ) |
| 🔐 ความลับ / background | ไม่มี เธอเชื่อทุกอย่างที่ศาสนจักรสอน |
| 📖 ผลต่อเรื่อง | ตอนที่ 1: อธิบายอาวุธ ช่วยพิธีเลือก · ตอนที่ 2-5 (ร่าง): ศรัทธาสั่นคลอนเมื่อเห็นความจริง อาจกลายเป็นคนในที่ช่วยผู้กล้าได้ (ทางเลือกของ DM) |
| 🎭 เล่นยังไง (โทน) | ตื่นเต้น สุภาพ พูดคำสอนอย่างจริงใจ ห้ามให้เธอโกหกโดยตั้งใจ ความน่าสงสารของเธอคือเธอไม่รู้ว่าตัวเองกำลังพูดคำโกหกของคนอื่น |

### ⛪ ซิสเตอร์ลิรา {#d-armory-lira}

*นักบวชผู้ช่วย อายุน้อย สุภาพ ตื่นเต้นที่ได้เห็นผู้กล้าจริง*

**🎭 เสียง**
- **จังหวะ:** เร็ว ตื่นเต้น พอประหม่าจะถอยเป็นเสียงเบา
- **สรรพนาม:** ตัวเอง = "ดิฉัน" · เรียกผู้เล่น = "ท่านผู้กล้า" · ลงท้าย "ค่ะ/คะ"
- **นิสัย:** อ้างคำสอน "ท่านมาเรนบอกว่า…" บ่อย · พูด "จริงๆ เลยค่ะ!" เมื่อตื่นเต้น · ขอโทษตัวเองทันทีที่เสียงดังเกินควร
- **ท่าทาง:** ประสานมือไว้ที่อก ตาเป็นประกาย ขยับเท้าเบาๆ เหมือนเด็กที่ยืนนิ่งไม่ค่อยได้
- **ไม่มีวันพูด:** สงสัยศาสนจักร หรือรู้ว่ามีผนึกในตราผู้กล้า (เธอไม่รู้จริงๆ)

**📜 บทตายตัว**

*ตอบคำถาม: "ทำไมอาวุธเลือกผู้ถือได้"*
> "ท่านมาเรนบอกว่าอาวุธเลือกหัวใจค่ะ! ท่านสอนว่าหัวใจที่ซื่อตรงจะได้ยินเสียงของมันก่อนใคร ดิฉันเองก็อยากได้ยินสักครั้ง… แต่ดิฉันไม่ใช่ผู้กล้านี่คะ ไม่เป็นไรค่ะ ได้เห็นท่านได้ยินก็พอแล้ว"

*เมื่อผู้เล่นทักเรื่องตราหน้าตาเหมือนกุญแจล็อก (หลังทอย 🎲 คัมภีร์ ค่าความยาก 13 ผ่าน)*
> "กุญแจเหรอคะ? ดิฉันเห็นเป็นลวดลายประดับนะคะ สวยดีออก… ท่านมาเรนคงรู้ดีกว่าดิฉันค่ะ"

*ปิดฉาก*
> "ขอให้อาวุธของท่านปกป้องท่านเสมอนะคะ! แล้วก็… ถ้ามีอะไรเล่าให้ดิฉันฟังได้เลยนะคะ ดิฉันชอบเรื่องผู้กล้ามากเลยค่ะ"

**🎲 ด้นต่อ**

| ผู้เล่นทำ | ลิราตอบโต้ |
|---|---|
| ถามเกี่ยวกับตัวเธอ | เธอเล่าเป็นชุดเร็วมาก จบด้วย "ขอโทษค่ะ ดิฉันพูดมากไป" |
| ถามเรื่องผู้กล้ารุ่นก่อน | "ในตำนานค่ะ! ดิฉันชอบเรื่องนั้นที่สุด ผู้กล้าที่ยืนกลางสงครามแล้วร้องเพลง…" (เล่าเรื่องในตำนานจริงจัง ไม่รู้ว่ามีจริง) |
| ถามเรื่องตรา | ตอบตามคำสอน "เป็นสัญลักษณ์แห่งการผูกใจกับอาวุธค่ะ" ไม่รู้เรื่องผนึก |
| แสดงความกลัว หรือคิดถึงบ้าน | เธอตกใจแล้วเข้ามาใกล้ทันที "ดิฉันขอโทษค่ะ ท่านต้องเหนื่อยมากแน่ๆ" ยื่นผ้าเช็ดหน้าให้ |
| ขอให้ช่วยเรื่องข่าวสาร | "ดิฉันไม่รู้อะไรหรอกค่ะ… แต่ท่านไปถามที่ห้องครัวสิคะ ป้าโมนารู้ทุกเรื่อง" |

**💬 กระเป๋าประโยค**
1. "จริงๆ เลยค่ะ! ท่านตัวจริงสูงกว่าที่ในหนังสือวาดไว้อีก"
2. "ดิฉันเห็นท่านแตะอาวุธแล้ว ขนลุกเลยค่ะ"
3. "ท่านมาเรนสอนว่าพลังที่แท้จริงมาจากใจที่ไม่หวั่นไหวค่ะ"
4. "อ๊ะ ขอโทษค่ะ ดิฉันพูดดังเกินไป… โอเรนมองแล้ว"
5. "ดิฉันสวดให้ท่านทุกเช้าเลยนะคะ ตั้งแต่ท่านมาถึง"
6. "ในโลกของท่านมีโบสถ์ไหมคะ? หน้าตาเป็นแบบไหน?"
