### 🔒 แฟ้ม (DM เท่านั้น — ห้ามอ่านออกเสียง)

| หัวข้อ | รายละเอียด |
|---|---|
| 🎯 อยากได้ | ให้ผู้กล้ารอดชีวิตรอบนี้ |
| 😨 กลัว | มาเรนที่ยืนอยู่ในห้อง และกลัวพูดผิดจนถูกเอาผิด |
| 💬 พูดได้ทันที (ไม่ต้องทอย) | ประวัติอาวุธแต่ละชิ้นตามที่เขียน |
| 🎲 ต้องทอยถึงจะรู้ | เคยเห็นผู้ถือรุ่นก่อนมาแล้ว "ดาบเล่มนี้เคยสั่นไม่หยุดเมื่อสามสิบปีก่อน" |
| 🚫 ไม่มีวันบอก | พูดตรงๆ ว่า "ผมเห็นผู้กล้ารุ่นก่อน" ไม่พูดอะไรเลยเมื่อมาเรนอยู่ในห้อง |
| 🔐 ความลับ / background | ทำงานห้องอาวุธมาหลายสิบปี เห็นผู้กล้ารุ่นก่อนถูกเรียกและหายไป ไม่กล้าเล่า |
| 📖 ผลต่อเรื่อง | ตอนที่ 1: ดูแลพิธีเลือกอาวุธ เบาะแสผู้กล้ารุ่นก่อน · ตอนที่ 2-5 (ร่าง): พยานที่กลับมาเล่าเต็มปากได้เมื่อราชสำนักเสียอำนาจ (ตอนที่ 5) |
| 🎭 เล่นยังไง (โทน) | ช้า พูดน้อย เช็ดแท่นหินซ้ำเมื่อกังวล ให้เบาะแสเป็นเสียงกระซิบครั้งเดียว แล้วกลับไปเช็ดแท่นเหมือนไม่มีอะไรเกิดขึ้น |

### 🧓 เฒ่าโอเรน {#d-armory-oren}

*ผู้ดูแลห้องอาวุธ วัยเกือบเจ็ดสิบ ช้า พูดน้อย ชอบเช็ดแท่นหินซ้ำๆ*

**🎭 เสียง**
- **จังหวะ:** ช้า ทีละคำ ประโยคขาดกลางคัน ลากเสียงท้ายด้วย "…ครับ"
- **สรรพนาม:** ตัวเอง = "ผม" · เรียกผู้เล่น = "ท่าน"
- **นิสัย:** พูดเรื่องสำคัญผ่านอาวุธ ไม่พูดตรงๆ ("ดาบเล่มนี้…" ไม่ใช่ "ผมเห็นผู้กล้าคนก่อน") · ถ้ารู้สึกว่าพูดมากไป จะถอยด้วยการเช็ดแท่นต่อ
- **ท่าทาง:** ผ้าเช็ดสีเทาเก่า เช็ดแท่นเดิมซ้ำๆ แม้ไม่มีฝุ่น · ไม่มองหน้าคนเวลาพูดเรื่องยากๆ
- **ไม่มีวันพูด:** "ผมเห็นผู้กล้ารุ่นก่อน" ตรงๆ · ไม่พูดเรื่องที่ไม่กล้ากับใครก็ตามเมื่อมาเรนอยู่ในห้อง

**📜 บทตายตัว**

*ตอบทั่วไป เมื่อผู้เล่นแตะอาวุธ*
> "…เล่มนั้นหรือครับ" *(พยักหน้าช้าๆ)* "มันดูพอใจนะ"

*เมื่อผู้เล่นยื่นชาให้ (ชาจากครัว [ป้าโมนา](#d-kitchen-mona) หรือจากรีลลา ให้ได้เปรียบในการทอยโน้มน้าว)*
> "ชา…" *(ถือถ้วยด้วยสองมือ)* "ไม่มีใครเอาชามาให้ผมที่นี่นานแล้วนะครับ"

🎲 **โน้มน้าวโอเรน ค่าความยาก 14 (ให้ชา = ได้เปรียบ)** → 🔍 ความสงสัย +1 เมื่อทอยผ่าน
*(เขาหยุดมือที่เช็ด มองแท่นดาบ ไม่มองผู้เล่น)*
> "ดาบเล่มนี้… เคยสั่นไม่หยุดเมื่อสามสิบปีก่อน" *(เสียงเบาลงเหลือแทบกระซิบ)* "…ลืมที่ผมพูดไปเถอะครับท่าน ผมแก่แล้ว พูดเลอะเทอะ"

*ถ้าถามตรงๆ โดยไม่ได้ให้ชา หรือทอยไม่ผ่าน*
> "ผมแค่เช็ดแท่นครับ ท่าน" *(เช็ดต่อ)* "…เช็ดแท่น"

*ปิดฉาก*
> "ขอให้มันอยู่กับท่านนานๆ นะครับ… มันเหงา"

**🎲 ด้นต่อ**

| ผู้เล่นทำ | โอเรนตอบโต้ |
|---|---|
| ชวนคุยเรื่องทั่วไป | ตอบสั้นๆ ทีละคำ ถ้าผู้เล่นใจเย็นพอ เขาจะเล่าเรื่องแท่นหินยาวกว่าที่คาด (ห้องนี้คือชีวิตเขา) |
| ช่วยเช็ดแท่นด้วย | นิ่งไปครู่ แล้วยื่นผ้าอีกผืนให้ พูดเบาๆ "…ตรงมุมนั้นนะครับ ไล่เป็นวงกลม" (ความไว้ใจเพิ่ม) |
| ถามเรื่องอาวุธที่เหลือ | ก้มหน้าเช็ดแท่นเร็วขึ้น "ท่านมาเรนเป็นคนดูแลครับ ผมไม่ยุ่ง" |
| ถามตรงเรื่องผู้กล้ารุ่นก่อน (ต่อหน้ามาเรน) | ตัวแข็ง "ผมไม่ทราบครับ" ไม่มองผู้เล่นอีกจนกว่ามาเรนไป |
| ขู่หรือกดดัน | ตกใจจนมือสั่น ผ้าเช็ดหล่น ไม่พูดอะไรเลย (เขาจะไม่ช่วยอีก) |

**💬 กระเป๋าประโยค**
1. "ระวังขั้นบันไดตรงกลางนะครับ ผมยังหาสาเหตุไม่ได้ว่าทำไมมันลื่น"
2. "แท่นนี้…ผมเช็ดทุกเช้า ผมไม่รู้ว่าเช็ดทำไม แต่รู้สึกว่าควรทำ"
3. "พวกมันหลับตอนกลางคืนนะครับ ท่านเชื่อไหม"
4. "ท่านมือเย็น ระวังไข้หวัดนะครับ ห้องนี้เย็น"
5. "…ผมไม่ค่อยได้คุยกับใครหรอกครับ ขอโทษถ้าพูดไม่เก่ง"
6. "เล่มนั้นเคยเป็นเล่มโปรดของ… ไม่มีอะไรครับ"
