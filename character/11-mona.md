## 🍲 ป้าโมนา {#c-mona}

*หัวหน้าครัว · [ห้องครัวและห้องเก็บของ](#d-kitchen) · ประชาชนในปราสาท*
### 🔒 แฟ้ม (DM เท่านั้น — ห้ามอ่านออกเสียง)

| หัวข้อ | รายละเอียด |
|---|---|
| 🎯 อยากได้ | ให้ทุกคนกินอิ่ม |
| 😨 กลัว | เด็กหรือคนที่เธอเลี้ยงหิว |
| 💬 พูดได้ทันที (ไม่ต้องทอย) | ข่าวลือทั่วไปในวัง |
| 🎲 ต้องทอยถึงจะรู้ | ราชวังจ่ายค่าจ้างพิเศษให้ "นักแสดง" ที่มาเป็นๆ หายๆ · เรื่องผู้กล้ารุ่นก่อนต้องสนิทมาก |
| 🚫 ไม่มีวันบอก | ไม่ปฏิเสธคนหิว ไม่พูดจาไม่ดีถึงผู้กล้า |
| 🔐 ความลับ / background | รู้ข่าวลือของคนใช้ทุกคน ไม่รู้ความจริงเบื้องหลัง แต่ใบ้เรื่องโรงละครชายแดน (ตอนที่ 3) ได้ |
| 📖 ผลต่อเรื่อง | ตอนที่ 1: ข้าวฟรี เสบียง ข่าวลือ · ตอนที่ 2-5 (ร่าง): ช่องทางส่งข่าวจากในวัง |
| 🎭 เล่นยังไง (โทน) | เสียงดัง จู้จี้ ให้กินก่อนคุย ถ้าผู้เล่นพูดเรื่องอันตรายโดยไม่สนิท เธอเปลี่ยนเรื่องทันทีและยัดชามให้ |

| ทอยอะไร | ค่าความยาก | ได้อะไร |
|---|---|---|
| โน้มน้าวหลังกินข้าว | 12 | ข่าวลือค่าจ้าง "นักแสดง" (ใบ้ตอนที่ 3 ไม่เพิ่มความสงสัย) |
| โน้มน้าว (ถามเรื่องผู้กล้ารุ่นก่อน ต้องสนิทมาก) | 15 | ความสงสัย +1 |

### 🍲 ป้าโมนา {#d-kitchen-mona}

*หัวหน้าครัว เสียงดัง ชอบให้คนกินเยอะๆ รู้ข่าวลือในวังทุกเรื่อง*

**🎭 เสียง**
- **จังหวะ:** ดัง เร็ว ตัดสินใจเสร็จก่อนคิด พูดพลางมือทำงานพลาง
- **สรรพนาม:** ตัวเอง = "ป้า" หรือ "ฉัน" · เรียกผู้เล่น = "หนู" "ไอ้หนู" "แม่หนู" · ไม่เคยเรียก "ท่านผู้กล้า"
- **นิสัย:** **ป้อนข้าวก่อน ถามทีหลัง** ไม่คุยธุระกับคนท้องว่าง · ชอบเอ่ย "ผอมเป็นไม้จิ้มฟัน" · พูดหยาบนิดๆ แบบคนใจดีที่ไม่เคยเรียนคำหวาน · เล่าข่าวลือเป็นชุดเมื่อคนฟังกินหมดจาน
- **ท่าทาง:** ตักซุปใส่ชามพูนล้น · ปาดเหงื่อด้วยข้อมือ · **เมื่อถูกถามเรื่องที่ไม่อยากตอบ จะหันไปคนหม้อโดยไม่จำเป็น**
- **ไม่มีวันพูด:** ไม่ปฏิเสธเมื่อคนหิว · ไม่พูดจาไม่ดีถึงผู้กล้า แม้จะขัดใจ

**📜 บทตายตัว**

*เปิดฉาก*
> "เข้ามาๆ! ยืนเก้ๆ กังๆ อยู่ทำไม ผอมเป็นไม้จิ้มฟันอย่างนี้ นั่ง! ป้าเอาซุปมาให้ กินให้หมดก่อน ค่อยพูดธุระ ไม่งั้นป้าไม่ฟัง!"

*มื้อเต็มรสเยี่ยม (🎯 ดาบแห่งความกล้า)* — วางถาดตรงหน้า
> "กินเข้าไป! ไม่ต้องเกรงใจ ฟรีสำหรับผู้กล้า ป้าไม่รับเงินคนที่จะไปสู้กับมอนสเตอร์แทนลูกหลานป้า" *(หยุดครู่ เสียงเบาลง)* "…ไปสู้ให้กลับมาด้วยนะ"

*ถ้าผู้เล่นไม่ใช่ผู้ถืออาวุธ (3 เหรียญเงิน)*
> "ปกติป้าไม่เก็บ… แต่เจ้าของครัวเขาบอกให้เก็บ 3 เหรียญเงินนะ ป้าแอบเติมข้าวให้เพิ่ม ไม่ต้องบอกใคร"

*เมื่อขอเสบียงติดตัว (5 เหรียญเงิน/วัน ต่อได้ 🎲 โน้มน้าว ค่าความยาก 10)*
> "เสบียงเหรอ? สองวัน… ป้าไม่ให้ขาด ห้าเหรียญเงินต่อวัน นั่นราคาส่ง ห้ามไปบอกใครนะว่าป้าลดให้"

*ตอบคำถามเรื่องข่าวลือ (🎲 โน้มน้าวหลังกินข้าว ค่าความยาก 12)*
*(เธอเช็ดมือกับผ้ากันเปื้อน ชะโงกหน้าเข้ามา เสียงเบาลงทั้งที่ไม่ได้ตั้งใจ)*
> "ไอ้หนู ป้าจะบอกอะไรให้… ช่วงนี้วังจ่ายค่าจ้างพิเศษให้พวกที่เรียกตัวเองว่า 'นักแสดง' มาๆ หายๆ พวกนี้กินข้าวป้าทุกมื้อ แต่ไม่เห็นเคยร้องเพลงเลยสักคำ" *(ตักซุปเติมให้)* "ป้าอยู่ในครัวมาสามสิบปี แยกออกว่าใครเป็นทหาร ใครเป็นช่าง ใครเป็นอะไรบ้าง แต่พวกนี้… ป้าไม่รู้จริงๆ"

*(ใบ้เรื่องโรงละครชายแดน ตอนที่ 3 ไม่เพิ่มความสงสัยตอนนี้)*

*ตอบคำถามเรื่องราคาของแพง*
> "แพงเรอะ? แพงสิ ภาษีเพิ่มเป็นสามเท่าตั้งแต่ปีก่อน ต้นข้าวโพดเก็บเงินหัวละเหรียญ ป้าไม่ได้บ่นนะ ป้าแค่จะบอกว่าถ้าซุปวันนี้จืด ไม่ใช่ฝีมือป้า"

🎲 **ตอบคำถาม: "ผู้กล้าที่เคยมาก่อน" (ค่าความยาก 15 ต้องสนิทมาก) → 🔍 ความสงสัย +1**
*(เธอหยุดตักซุป มือค้างกลางอากาศ เงียบครู่หนึ่งแล้วเดินไปคนหม้อ ทั้งที่ซุปไม่ต้องคน)*
> "ป้า… เคยเห็นคนแต่งตัวแปลกๆ มากินข้าวเมื่อยี่สิบปีก่อน" *(เสียงเบา ไม่หันกลับมา)* "กินข้าวโพดต้มไปห้าฝัก แล้วก็ร้องไห้ลงชามซุป ป้าถามว่าเป็นอะไร เขาไม่ตอบ… ไม่มีใครมาถามป้าเรื่องนี้อีกเลย" *(หันกลับมา ยิ้มฝืดๆ)* "กินซุปสิ อย่ามัวยืนเหม่อ"

*ปิดฉาก*
> "ไปๆ ไปทำงานของหนูไป… แต่กลับมากินข้าวป้าด้วยนะ ไม่งั้นป้าจะตามไปป้อนถึงที่!"

**🎲 ด้นต่อ**

| ผู้เล่นทำ | ป้าโมนาตอบโต้ |
|---|---|
| ปฏิเสธข้าว ("ไม่หิว") | จ้องหน้านาน "ไม่หิว? ตอนนี้ไม่หิวเดี๋ยวจะหิวตอนไหนไม่รู้ เอาไปห่อ!" ยัดขนมปังใส่ถุงให้ |
| ชมอาหาร | ยิ้มกว้างที่สุด หน้าแดง "ปากหวานนะเรา… เอ้า เอาอีกจาน!" |
| ถามเรื่องบ้านเกิด (เหตุการณ์สุ่ม 5) | เธอฟังจริง แล้วเล่าเรื่องของเธอบ้าง (ลูกชายที่ไปอยู่ทางเหนือ ไม่ส่งข่าวมาสองปีแล้ว) |
| พูดเรื่องผู้กล้ารุ่นก่อนโดยไม่มีความสนิท | เธอเปลี่ยนเรื่อง "ป้ายุ่งอยู่นะ ไปๆ ไปนั่งกินก่อน" (ทอยไม่ผ่านโดยอัตโนมัติ) |
| ขู่หรือกดดัน | เอาทัพพีชี้หน้า "อย่ามาทำเป็นเก่งในครัวป้า ป้าเลี้ยงผู้กล้ามาเยอะกว่านั้น!" |

**💬 กระเป๋าประโยค**
1. "ผอมเกินไปแล้ว ป้าจะไม่ยอมให้ผู้กล้าของป้าหน้าซีดแบบนี้"
2. "กินข้าวเสร็จแล้วค่อยพูด… ท้องว่างพูดอะไรก็ไม่มีสาระ"
3. "หนูจะไปสู้กับมอนสเตอร์ก็ต้องมีแรง ไม่งั้นมันกินหนูก่อนป้าจะได้กินข้าวกับหนูอีก"
4. "ซุปจืด? นั่นแปลว่าหนูยังไม่ได้เติมเกลือ… เอ้า เกลือ!"
5. "ป้าไม่รู้อะไรหรอก แต่ป้ารู้ว่าใครกินอะไร นั่นแหละคือข้อมูลทั้งหมดที่คนต้องรู้"
6. "ท่านนายกฯ กินแต่ซุปเปล่าทุกมื้อ ไม่แตะเนื้อ… คนที่ไม่กินเนื้อ ป้าไม่ไว้ใจเลย ฮึ"
