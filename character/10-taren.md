## 📚 ทาเรน {#c-taren}

*ผู้ช่วยบรรณารักษ์ เด็กหนุ่มขี้อาย · [ห้องสมุดหลวง](#d-library) · ราชสำนัก (ใจอยู่กับผู้กล้า)*
### 🔒 แฟ้ม (DM เท่านั้น — ห้ามอ่านออกเสียง)

| หัวข้อ | รายละเอียด |
|---|---|
| 🎯 อยากได้ | เพื่อนที่ชอบตำนานผู้กล้าเหมือนกัน |
| 😨 กลัว | มิริเอลรู้ว่าเขาแอบอ่านชั้นต้องห้าม |
| 💬 พูดได้ทันที (ไม่ต้องทอย) | ตำนานผู้กล้าที่พิมพ์ในหนังสือ |
| 🎲 ต้องทอยถึงจะรู้ | ช่วยเปิดชั้นต้องห้ามเมื่อสนิทแล้ว |
| 🚫 ไม่มีวันบอก | ไม่บอกว่าแอบอ่านชั้นต้องห้าม (จนกว่าจะสนิท) |
| 🔐 ความลับ / background | อ่านชั้นต้องห้ามมาหลายเล่ม เริ่มสงสัยว่าตำนานกับบันทึกจริงไม่ตรงกัน แต่ไม่กล้าสรุป |
| 📖 ผลต่อเรื่อง | ตอนที่ 1: ประตูสู่ชั้นต้องห้าม (บันทึกผู้กล้ารุ่นก่อน คัมภีร์ถอดผนึก) · ตอนที่ 2-5 (ร่าง): พันธมิตรความรู้ของทีม อาจถูกลงโทษถ้ามิริเอลรู้ |
| 🎭 เล่นยังไง (โทน) | พูดเบา หน้าแดงง่าย ตาเป็นประกายเมื่อได้พูดถึงผู้กล้า ความสนิทต้องสะสมจากการสนใจเรื่องที่เขาชอบ |

**🎲 ทอยกับเขา**

| ทอยอะไร | ค่าความยาก | ได้อะไร |
|---|---|---|
| โน้มน้าว (ขอให้ค้นหา 5 เงิน) | 10 | พาไปชั้นที่ตรงหัวข้อ |
| โน้มน้าวเปิดชั้นต้องห้าม (เมื่อสนิท) | 14 | เข้าชั้นต้องห้าม 🔍 |

### 📚 ทาเรน {#d-library-taren}

*เด็กหนุ่มผู้ช่วยบรรณารักษ์ ขี้อาย ชอบอ่านตำนานผู้กล้า แอบอ่านหนังสือต้องห้ามบ่อยๆ*

**🎭 เสียง**
- **จังหวะ:** ติดขัด พูดเบา หยุดกลางประโยคเวลาประหม่า พอพูดถึงเรื่องที่ชอบจะเร็วขึ้นแล้วรีบเบรกตัวเอง
- **สรรพนาม:** ตัวเอง = "ผม" · เรียกผู้เล่น = "ท่านผู้กล้า" · ท้ายคำ "ครับ" เบาๆ
- **นิสัย:** ชอบเล่าตำนานผู้กล้า เล่าเพลินแล้วหยุดทันทีเมื่อได้ยินเสียงมิริเอลไอ · ไว้ใจง่ายเมื่อมีคนสนใจสิ่งที่เขาชอบ · **รู้สึกผิดที่แอบอ่านชั้นต้องห้ามแต่หยุดไม่ได้**
- **ท่าทาง:** กอดหนังสือไว้กับอกเหมือนโล่ · เหลือบมองมิริเอลบ่อย · สีหน้าเปลี่ยนเร็ว
- **ไม่มีวันพูด:** ไม่บอกว่าแอบอ่านชั้นต้องห้าม (จนกว่าจะสนิท)

**📜 บทตายตัว**

*เปิดฉาก (เมื่อมิริเอลเรียกให้พาไป)*
> "เอ่อ… ทางนี้ครับ ท่านผู้กล้า" *(กอดหนังสือ)* "ผมทาเรนครับ ผมอ่านเรื่องท่านมาเยอะมาก… หมายถึงผู้กล้าครับ ไม่ใช่ท่านโดยเฉพาะ ขอโทษครับ"

*เมื่อผู้เล่นถามเรื่องผู้กล้ารุ่นก่อน (เสียงเบา หันไปมองมิริเอลก่อน)*
> "ในตำนานมีครับ ผู้กล้าที่ยืนกลางสงครามแล้วร้องเพลง… แต่ท่านมิริเอลบอกว่าเป็นแค่นิทาน" *(เม้มปาก)* "ผม… ไม่แน่ใจว่านิทานหรือเปล่าครับ"

🎲 **โน้มน้าวทาเรนเปิดชั้นต้องห้าม ค่าความยาก 14 (เมื่อสนิทแล้ว)**
*(เขากระซิบแทบไม่ได้ยิน เล็งมิริเอลที่กำลังหันหลังให้)*
> "ผม… ไม่ควรบอกนะครับ แต่ผมเคยเห็นหน้าที่ถูกฉีกในชั้นนั้น… หน้าที่ถูกฉีกมันมี… ลายมือของคนที่ไม่ได้เขียนภาษาของเรา" *(กลืนน้ำลาย)* "ท่านมิริเอลแตะกุญแจตลอดเวลาที่มีใครถามเรื่องนี้ ผมรู้ ผมเห็นครับ"

*ปิดฉาก*
> "ถ้าท่านอยากอ่านเรื่องผู้กล้าอีก มาหาผมได้ครับ… ผมมีเล่มโปรดซ่อนไว้"

**🎲 ด้นต่อ**

| ผู้เล่นทำ | ทาเรนตอบโต้ |
|---|---|
| ถามเรื่องตำนานผู้กล้า | เล่าเพลินยาว ตาเป็นประกาย จนได้ยินเสียงไอของมิริเอล แล้วหน้าแดงหยุดทันที |
| เป็นมิตร ยกย่องความรู้ | เขาซึ้ง เสียงสั่น "ไม่มีใครเคยบอกว่าผมรู้เยอะเลยครับ" |
| ช่วยเก็บหนังสือหล่น (เหตุการณ์สุ่ม 2) | ขอบคุณจนน้ำตาซึม "ท่านใจดีมากครับ" (ความไว้ใจเพิ่ม) |
| ถามตรงๆ เรื่องชั้นต้องห้าม | ตัวแข็ง ส่ายหัวเร็วๆ "ไม่ครับ… ผมไม่เคยเข้าไป" (โกหกไม่เนียน) |
| ให้ของขวัญเป็นหนังสือหรือหมึก | เขาลืมกลัวแล้วยิ้ม "ให้ผมจริงเหรอครับ" |

**💬 กระเป๋าประโยค**
1. "ผมชอบตอนที่ผู้กล้าร้องเพลงให้ศัตรูฟังครับ ตอนนั้นสงครามหยุดไปหนึ่งคืน"
2. "ชั้นบนสุดมีหนังสือเก่าที่ไม่มีใครอ่านแล้ว… ผมอ่านหมดทุกเล่ม"
3. "ท่านมิริเอลดุนะครับ แต่ใจดีจริงๆ ท่านแค่ไม่ชอบแสดง"
4. "ผมไม่เคยเห็นผู้กล้าตัวเป็นๆ เลยครับ ท่านเหมือนในหนังสือ… ไม่สิ ดีกว่าเยอะเลย"
5. "ถ้าท่านหลงทางในห้องนี้ให้ตามกลิ่นหมึกครับ มันหนาขึ้นเรื่อยๆ ตรงกลาง"
6. "ผม… อยากเป็นผู้กล้าครับ ขอโทษที่พูดออกมา"
