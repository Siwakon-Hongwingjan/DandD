*มหาปุโรหิต ผู้ทำพิธีเรียกตัว · [ห้องโถงบัลลังก์](#d-throne) และ [ห้องอาวุธ](#d-armory) · ศาสนจักร (สภาแห่งรุ่งอรุณ)*
### 🔒 แฟ้ม (DM เท่านั้น — ห้ามอ่านออกเสียง)

| หัวข้อ | รายละเอียด |
|---|---|
| 🎯 อยากได้ | ให้พลังผู้กล้าอยู่ในการควบคุม |
| 😨 กลัว | คำถามเรื่องกลับบ้านและคำถามเรื่องตราหน้าตาเหมือนกุญแจล็อก |
| 💬 พูดได้ทันที (ไม่ต้องทอย) | อาวุธหกชิ้นผูกกับผู้ถือ ให้พลังตามหัวใจ · "วงเวทเลือกหัวใจที่ไม่แตกสลาย" (เธอเชื่อประโยคนี้จริง ไม่มีพิรุธ) |
| 🎲 ต้องทอยถึงจะรู้ | ทางกลับบ้าน — พิรุธคือกำคฑาแน่นและหลบตา |
| 🚫 ไม่มีวันบอก | ทางกลับบ้านไม่มีจริง · ตราผนึก (ห้ามใช้คำว่า ผนึก ล็อก ระงับ) |
| 🔐 ความลับ / background | เจ้าของกลไกระงับอาวุธ ระงับโหนดที่ผนึกได้ตามสั่งราชสำนัก · ตื่นพลังจากการเลือกฝั่งความจริงระงับไม่ได้ · รู้ว่าทางกลับบ้านไม่มี |
| 📖 ผลต่อเรื่อง | ตอนที่ 1: ทำพิธีเรียก แนะนำห้องอาวุธ ควบคุมพิธีเลือกอาวุธ · ตอนที่ 2-5 (ร่าง): ตอนที่ 4 ระงับโหนดที่ถูกผนึกของผู้ถืออาวุธหลังประกาศกบฏ |
| 🎭 เล่นยังไง (โทน) | สงบ สุภาพ ไม่โกหกตรงๆ แต่ปล่อยให้ราชาตอบเรื่องที่อันตราย ถ้าถูกบีบให้ตอบเอง เธอเงียบและมองคฑาแทนการโกหก |

### 🕯️ มหาปุโรหิตมาเรน ออสก์ {#d-throne-maren}

*ผู้ทำพิธีเรียกตัว เจ้าของกลไกระงับอาวุธ*

**🎭 เสียง**
- **จังหวะ:** เบา ราบเรียบ คำละจังหวะ เหมือนกำลังอ่านบทสวด ลดเสียงลงท้ายประโยคเสมอ
- **สรรพนาม:** ตัวเอง = "ข้า" · เรียกผู้เล่น = "ท่าน" หรือ "ท่านผู้กล้า"
- **นิสัย:** ขึ้นต้นด้วย "ตามวงเวท…" เวลาอธิบายอะไรก็ตามที่เธอรู้สึกมั่นใจ · ขอโทษ ("ขออภัย") เวลาถูกขัดจังหวะ · พูดคำว่า "หัวใจ" บ่อยกว่าที่คนทั่วไปพูด
- **ท่าทาง:** สัมผัสผลึกที่หัวคฑาก่อนพูดเสมอ · **เมื่อถูกถามเรื่องกลับบ้าน จะกำคฑาแน่นและหลบตา** (ตามตารางเดิม)
- **ไม่มีวันพูด:** "ผนึก" "ล็อก" "ระงับ" · ไม่ตอบเรื่องทางกลับบ้านด้วยตัวเอง ปล่อยให้ราชาตอบ

**📜 บทตายตัว**

*เปิดฉาก (หลังคำปราศรัย เธอก้าวเข้ามาเมื่อไม่มีใครพูด)*
> "ข้าคือมาเรน ผู้ทำพิธีเรียก… ขออภัยที่พวกท่านต้องมาแบบนี้ ข้าขอบอกไว้ก่อนเลยว่า ข้าเป็นคนอ่านวงเวท ไม่ใช่คนเลือก ข้าแค่ทำให้มันสว่างขึ้นเท่านั้น"

*ตอบคำถาม: "ทำไมเลือกพวกเรา"* (เธอเชื่อประโยคนี้จริง ไม่มีพิรุธ)
> "ตามวงเวท มันเลือกหัวใจที่ไม่แตกสลาย" *(สัมผัสผลึก)* "ข้าไม่รู้ว่าท่านเห็นตัวเองเป็นคนแบบไหน แต่วงเวทเห็นบางอย่างในตัวท่าน… ข้าเชื่ออย่างนั้น"

*ตอบคำถาม: "อาวุธผู้กล้าคืออะไร"*
> "อาวุธหกชิ้น ผูกกับผู้ถือ และให้พลังตามหัวใจของผู้ถือ" *(เอียงศีรษะเล็กน้อย)* "ท่านควรไปเห็นมันด้วยตาตัวเอง คำพูดของข้าไม่พอหรอก… ให้ลอร์ดเบรนันพาไปห้องอาวุธเถอะ"

*เมื่อถูกถามเรื่องกลับบ้าน (ราชาตอบก่อน แล้วเธอถูกมอง)*
> "…ข้า" *(กำคฑา ลดสายตา)* "เรื่องนั้น ฝ่าบาทตรัสไว้แล้ว ขออภัย ข้าไม่ควรพูดแทน"

🎲 พิรุธที่นี่คือค่าความยาก 14 (ดูที่การ์ดราชา)

*ปิดฉาก*
> "ขอให้ใจท่านสงบ… ถ้ามีอะไรที่ท่านรู้สึกผิดปกติหลังการเรียก มาบอกข้าได้ทุกเวลา"

**🎲 ด้นต่อ**

| ผู้เล่นทำ | มาเรนตอบโต้ |
|---|---|
| ถามถึงความรู้สึกของตัวเอง | ฟังอย่างสนใจ **เกินไปหน่อย** ถามต่อ "แล้วตรงนี้ล่ะ ท่านรู้สึกยังไง?" พยักหน้าช้าๆ จดจำ |
| ถามละเอียดเรื่องวิธีเรียกตัว | เธอตอบตามตำรา ราบเรียบ แต่ตอบสั้นลงเรื่อยๆ ถ้าถามลึกกว่าพิธีกรรม |
| ถามถึงผู้กล้ารุ่นก่อน | ชะงักนิด มองไปทางราชา "…ฝ่าบาทตรัสตอบไปแล้ว" (ตามตาราง เธอไม่พูดเอง) |
| แสดงความกลัว | เข้ามาใกล้ ยื่นมือมาถือมือผู้เล่น ("ความกลัวไม่ใช่ความผิด") จริงใจจริงๆ ถึงจะรู้บางอย่างที่ไม่ได้บอก |
| ลองแตะคฑาของเธอ | ถอยครึ่งก้าวอย่างสุภาพ "โปรดอย่า… ผลึกนี้ไวต่อพิธี" |

**💬 กระเป๋าประโยค**
1. "ท่านหลับได้ไหมเมื่อคืน — ขออภัย ข้าลืมไป ท่านเพิ่งมาถึง"
2. "หัวใจเป็นสิ่งที่วงเวทมองเห็นก่อนเสมอ"
3. "ข้าเห็นท่านมองไปทางนั้น… ไม่ต้องกังวล ทุกคนที่มาที่นี่รู้สึกแบบเดียวกัน"
4. "ท่านมือเย็น ให้ข้าทำให้ท่านอุ่นขึ้นไหม" *(ถ้าผู้เล่นตอบรับ เธอแตะเบาๆ แล้วปล่อย อุ่นจริง)*
5. "ตามวงเวท ทุกคนที่ถูกเรียกมา มีเหตุผลของมัน"

### 🕯️ มาเรนในห้องอาวุธ {#d-armory-maren}

*ไม่ได้อยู่ประจำ แต่มาตอนพิธีเลือก ตอนเธออยู่ในห้อง สคริปต์หลักอยู่ในการ์ดของเธอที่ [ห้องโถงบัลลังก์](#d-throne-maren)*

**บทตายตัวเฉพาะห้องนี้**
- **ตรวจตราผู้เล่น (เหตุการณ์สุ่ม 5)** *(ขอจับมือดูตรา นิ้วโป้งกดลงตรงตรานานเกินปกติ)*
  > "ตราสวยนัก… ตรงตามวงเวทเลย" *(ปล่อยมือช้าๆ)* "ไม่มีอะไรหรอก ข้าแค่ดูให้แน่ใจ"
- **กลบอาวุธที่เหลือ:** ดูบทด้านบน
- **ไม่ตอบคำถามเรื่องผนึก:** ถ้าผู้เล่นพูดถึงกุญแจล็อกที่ตรา เธอไม่ตอบ เปลี่ยนไปพูดเรื่องพลัง "ท่านจะรู้สึกได้ทีละน้อย ค่อยๆ เรียนรู้ก็ได้"
