| 🎯 อยากได้ | ที่ปลอดภัย และอยากได้ผ้าห่อของแม่คืนมาอยู่กับตัวตลอด |
| 😨 กลัว | คนแปลกหน้าทุกคนที่ไม่ได้มาจากหมู่บ้านของเธอ |
| 💬 พูดได้ทันที (ไม่ต้องทอย) | ไม่มี — เธอไม่พูดกับคนที่ยังไม่ไว้ใจ |
| 🎲 ต้องทอยถึงจะรู้ | ตามรอยไปพบเธอในห้องใต้ดิน |
| 🚫 ไม่มีวันบอก | ชื่อ แม่ หรือที่มา ถ้ายังไม่ไว้ใจ |
| 🔐 ความลับ / background | ชนเผ่าเถ้าถ่านมีเลือดปีศาจจริงแต่เป็นชาวบ้านธรรมดา หมู่บ้านของเธอถูกเผาโดยฝีมือคนที่รู้วิธีทำให้ "เหมือนสัตว์ร้าย" (เบาะแส Z1) เธอถือผ้าห่อของแม่ไว้ตลอด |
| 📖 ผลต่อเรื่อง | ตอนที่ 1: เจอที่ซาก (ผู้ที่ลงจอดนอกเมือง) เป็นภาพแรกของ "ผู้ถูกป้ายสี" · ตอนที่ 2-5 (ร่าง): ตะขอตอนที่ 2 ถ้าผู้เล่นใจดี เชื่อมไปกลุ่มตะเกียงลับ และแม่วีซาในตอนที่ 4 |
| 🎭 เล่นยังไง (โทน) | เบา เกือบไม่ได้ยิน คำสั้นทีละคำ ไม่มองหน้า ให้ผู้เล่นเคารพพื้นที่ของเธอ ความไว้ใจมาจากการที่ผู้เล่นไม่แตะผ้าห่อของแม่ |

### ⭐ เทช่า {#d-ruined-village-tesha}

*เด็กหญิงชนเผ่าเถ้าถ่านวัย 10 ปี ผู้รอดชีวิต 1 คน หวาดกลัว ขี้ระแวง (ตะขอตอนที่ 2 ถ้าผู้เล่นใจดี)*

**🎭 เสียง:** เบามาก เกือบไม่ได้ยิน พูดสั้นทีละคำ ราวกับตรวจว่าคำนั้นปลอดภัยไหมก่อนปล่อยออกมา · "หนู" เรียกผู้เล่น "ท่าน" (สุภาพเกินเด็ก เพราะเรียนมาให้ระวังคนแปลกหน้า) · **ไม่บอกชื่อจนกว่าจะไว้ใจ** · จ้องรองเท้าผู้เล่นก่อนหน้า · ไม่มีวันพูดถึงแม่หรือที่มาถ้ายังไม่ไว้ใจ · **ท่าทาง:** ผ้าคลุมสีเทาเก่าปักลายสีดำแดง ขอบตาแดงแต่ไม่ร้องไห้ กอดผ้าห่อหนึ่งไม่ปล่อย

**📜 บทตายตัว**

*🎲 เมื่อผู้เล่นตามรอยพบ (เอาตัวรอด ค่าความยาก 13 พบเธอในห้องใต้ดินบ้านหลังหนึ่ง)*
> *(เธอนั่งหลังกองไม้ในความมืด ตัวหดเล็กที่สุดเท่าที่จะทำได้ ตาเปล่งแสงเล็กน้อยจากช่องแสงที่ลอดเข้ามา เธอไม่ขยับ ไม่พูด นานจนผู้เล่นเกือบคิดว่านับผิดคน)* "…ท่านเป็นทหารไหม" *(เสียงเบาจนเกือบกลืนหายไปกับความมืด)*

*ถ้าผู้เล่นตอบว่าไม่ / ไม่แตะต้องเธอ / ยื่นอาหาร*
> *(มองมือที่ยื่นอาหารนานมาก ไม่รับทันที สายตาเลื่อนลงไปที่รองเท้าผู้เล่นแทน)* "…รองเท้าท่านไม่เหมือนของพวกนั้น" *(รับช้าๆ กัดคำเล็กๆ ไม่ละสายตาจากผู้เล่น)* "ท่านไม่ใช่พวกเขา" *(หยุดคิดนาน)* "…แต่หนูยังไม่อยากบอกชื่อ แม่บอกไม่ให้บอกใคร"

*ถ้าผู้เล่นถามว่าเกิดอะไรขึ้น*
> *(กอดผ้าห่อแน่นขึ้นก่อนเริ่มพูด)* "ไฟ" *(หยุดยาว)* "วันที่ฟ้ามืดกว่าปกติ ผู้ชายพวกนั้นมาพร้อมกันหลายคน" *(เสียงเริ่มสั่น)* "ไม่พูดอะไรเลย… ไม่ต้องพูด" *(ก้มหน้าลงจนมองไม่เห็นตา)* "หนูซ่อนอยู่ใต้พื้น" *(เงียบไปนาน ก่อนพูดต่อเบาที่สุด)* "หนูนับเวลา… นับได้สามปี"

*ถ้าผู้เล่นถามว่าเธออยู่ตรงนี้คนเดียวมาสามปีหรือ (เธอตอบบางส่วน ไม่ใช่ทั้งหมด)*
> "หนูไม่ได้อยู่ตรงนี้ตลอด" *(เงยหน้าขึ้นเล็กน้อย เหมือนอยากให้เข้าใจถูก)* "หนูออกไปหาอาหาร กลับมานอนตอนกลางคืน…" *(เงียบไปพักหนึ่ง นิ้วลูบขอบผ้าห่อ)* "มีคนมาหาหนูเดือนละครั้ง" *(เสียงอ่อนลงอีก)* "เอาข้าวมาให้ ไม่เคยบอกชื่อ เอาตะเกียงเล็กๆ วางไว้หน้าประตูทุกครั้ง"

*เมื่อไว้ใจแล้ว (ให้ผู้เล่นเลือกเปิดตะขอตอนที่ 2)*
> "…หนูชื่อเทช่า" *(กระซิบเหมือนบอกความลับที่หนักที่สุดในชีวิต)* "ท่านอย่าบอกใครนะ" *(มองไปทางประตูก่อนพูดต่อ)* "ที่ทางเหนือมีทางเก่าในป่า ข้ามไปได้ มีคนที่เป็นของพวกเรายังอยู่ตรงนั้น" *(หยุดนาน กลืนน้ำลาย)* "แม่บอกว่าถ้าวันไหนมีคนใจดีมา ให้บอกเรื่องนี้" *(มองตาผู้เล่นตรงๆ เป็นครั้งแรก)* "หนูไม่รู้ว่าท่านใจดีจริงไหม" *(เสียงเบาลงอีกจนแทบไม่ได้ยิน)* "แต่หนูอยากลอง"

**🎲 ด้นต่อ**

| ผู้เล่นทำ | เทช่าตอบโต้ |
|---|---|
| ยื่นอาหารโดยไม่ถามอะไร | เธอนิ่งนานที่สุด แล้วรับ ไม่กินตรงหน้าผู้เล่น แต่กอดห่อไว้แน่นตอนจากไป |
| จะจับตัวหรือพากลับเมือง | เธอวิ่งหนีทันที เร็วผิดคน ผู้เล่นไล่ไม่ทัน เธอจะไม่ปรากฏอีกในฉากนี้ |
| ตามไปดูที่ซ่อน | เธอกอดผ้าห่อแน่นและยืนขวางประตูห้องใต้ดิน "ไม่ได้… ของแม่หนู…" (ผู้เล่นเคารพ = ไว้ใจเพิ่ม) |
| พูดกับเธออย่างเงียบๆ ไม่ถามอะไร | เธอนั่งลงข้างผู้เล่นทีละนิดโดยไม่รู้ตัว จนสุดท้ายนั่งติดกัน |
| เป็นผู้ถืออาวุธ (มีตรา) | เธอเห็นตราแล้วถอยหนึ่งก้าว "ตรานั้น… ผู้กล้าเหรอ… คนของพวกเขา" (ยากขึ้น ต้องพิสูจน์ด้วยการกระทำ) |
